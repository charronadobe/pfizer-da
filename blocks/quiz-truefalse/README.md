# quiz-truefalse

Custom **quiz** block. Purpose: true-false-knowledge-check.

## Authoring (Document Authoring)

| Row | Cells |
| --- | --- |
| Statement | one cell: eyebrow paragraph, statement heading (h2), optional italic source line |
| One row per answer | answer label (e.g. "True") \| feedback for that answer (heading, text, optional CTA link) \| optional third cell: any text marks the correct answer |
| Explanation (optional) | one cell: content shown after any answer (text, CTA link) |

Behaviour and design:

- Renders as a light-blue rounded card; a `light-blue` section around it is shown on the page background so the card stays visible.
- Choosing an answer fills that tile and widens it, and reveals a white result card. Readers can change their answer.
- When a correct answer is marked, the result shows a correct (green check) or incorrect (red warning) icon.
- CTA links in the result render as small outlined pills; off-site links get an external-link glyph.
