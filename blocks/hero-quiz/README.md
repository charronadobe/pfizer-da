# hero-quiz

Custom **hero** block. Purpose: quiz-launch-hero.

## Authoring (Document Authoring)

Model: `standalone`

Single block table.

- Row 1, one cell: optional eyebrow paragraph (e.g. **IN THE FIGHT AGAINST CANCER**), the
  heading (e.g. `EVERY SCREEN MATTERS.`), subtitle paragraph(s), the CTA link (bold = primary
  button), then a note paragraph (icon image + text, e.g. clock + "30 seconds").
  A bold lead-in at the start of the heading (`# **Eyebrow** Heading`) is also shown as the eyebrow.
- Row 2 (optional), one cell: returning-visitor CTAs (bold = primary, italic = outlined), shown
  instead of the row 1 CTA when `sessionStorage` holds `quiz-results`.
