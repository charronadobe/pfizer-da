# quote-photo

Custom **quote** block. Purpose: patient-testimonial.

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one row with two cells:

1. Image(s): first picture is the desktop photo, an optional second picture is used below 900px.
2. Content: quote heading (or paragraph), italic attribution paragraph (bold name, line break, role), optional CTA link.

Same-origin images are optimized with `createOptimizedPicture`; external (absolute) image URLs are kept as authored.

## Supported variations

No variations.
