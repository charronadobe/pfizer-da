# cards-fact

Custom **cards** block. Purpose: key-facts.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Authoring notes

- One row per card: topic question (h3), statement (a second h3, or a fully bold paragraph), explanatory paragraph(s).
- Optional: end the card with a paragraph containing only a link; it renders as a bold, underlined text link below the card text.
- Layout is automatic: 1 column on mobile; from 900px two per row, or three across when the block has exactly 3 cards.
