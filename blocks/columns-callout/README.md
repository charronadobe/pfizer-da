# columns-callout

Custom **columns** block. Purpose: partner-callout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: logo image | heading + paragraph(s).
A single cell with the logo paragraph first also works. The leading heading becomes the
panel title; logo, title and copy stack centered on mobile and sit in a logo | text grid
from 900px.
