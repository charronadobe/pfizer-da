# cards-icon

Custom **cards** block. Purpose: icon-feature-list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Two column (icon list in two columns) | `two-column` |
| One column (icon left of copy on desktop too, section heading on the left) | `one-column` |

Default: 3 per row on desktop. On mobile/tablet all variants stack in one column with the icon
left of the copy and a divider between items. SVG icons are tinted in the brand blue.
