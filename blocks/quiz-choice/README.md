# quiz-choice

Custom **quiz** block. Purpose: choose-a-concern-reveal.

## Authoring (Document Authoring)

Model: `standalone`

Single block table:

- First row (one cell): the question heading (and optional intro text).
- One row per option (two cells): option label | answer content (heading, paragraphs, CTA link).
- Optional trailing row (one cell): content appended below every answer.

Choosing an option reveals its answer card (inline under the tile on mobile, below the tile
grid from 900px); choosing it again closes it. CTA links render as small primary buttons.
